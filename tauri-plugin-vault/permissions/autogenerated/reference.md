## Default Permission

Pick a vault folder, then list, read, write and delete files inside it.

#### This default permission set includes the following:

- `allow-pick`
- `allow-list`
- `allow-read`
- `allow-write`
- `allow-remove`
- `allow-remove-dir`
- `allow-list-dir`
- `allow-exists`
